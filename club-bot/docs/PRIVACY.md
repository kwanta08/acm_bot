# プライバシーポリシー

鳥人間サークル 統合運営 Discord Bot（以下「本Bot」）が取り扱う情報について定めます。

- 版: 初版（公開時に発効）
- 最終更新: 2026-08-08

> **公開前に記入が必要な項目**（P0-5 の Public Bot 有効化と合わせて確定させること）
> - `〈運営者〉`: 本Botを運用する個人または団体の名称
> - `〈連絡先〉`: 問い合わせ・削除請求の窓口
> - `〈サーバー所在地〉`: データを保存する VPS のリージョン（例: 日本国内）

---

## 1. 運営者

本Botは `〈運営者〉` が単一のインスタンスとして運用しています。
本Botを招待した各サーバー（以下「導入サーバー」）のデータは、
運営者が管理するデータベースに保存されます。

## 2. 収集する情報

本Botは、コマンドの実行、リアクション操作、およびボタン・選択メニューの操作を通じて
次の情報を記録します。
**すべての情報は導入サーバーの ID（`guild_id`）に紐づけて保存されます。**

新入生オンボーディング（`WELCOME_ENABLED`。**既定は OFF**）を有効にしたサーバーでは、
参加した方へ班を選ぶ案内をお送りします。**名簿（メンバー情報）に登録されるのは、
班を選んでいただいたときだけ**です。参加しただけでは名簿に登録されません。

なお、表示名の解決用キャッシュ（下表）は、この設定に関わらず、Bot の起動時にサーバーの全メンバー分が更新されます。

### 2.1 利用者に関する情報

| 情報 | 内容 | 記録される場面 |
|---|---|---|
| Discord ユーザーID | 数値の識別子（スノーフレーク） | メンバー登録・出欠回答・タスク登録・積層記録・各種操作時 |
| 表示名 | サーバー上の表示名（ニックネーム） | `/member register`、`/setup` などでの登録時、新入生オンボーディングで班を選んだ時 |
| 所属班・副所属班・班長フラグ | 班の割り当て情報 | `/member assign-team` `/member setup` 等、新入生オンボーディングで班を選んだ時 |
| メモ | メンバーに対する任意の自由記述 | 管理者が入力した場合のみ |
| 表示名キャッシュ | ダッシュボードで ID を名前へ解決するための表示名 | Bot の起動時（サーバーの全メンバー分）・サーバーへの参加時・ニックネーム変更時（設定に関わらず） |
| 出欠回答 | 候補日時ごとの ○ / △ / × の別と更新日時 | 日程調整のリアクション操作時 |
| タスク情報 | **Bot は保存しません。** `/task` で作成したタスクは Todoist 側にのみ保存されます（Todoist のプライバシーポリシーが適用されます） | `/task add` 等 |
| 桁巻き積層の作業記録 | 実行者・桁名・層番号・開始時刻・終了時刻・作業時間（分） | `/layer start` `/layer end` |
| 操作の監査ログ | 操作者のユーザーID・操作名・対象・詳細・日時 | 管理者操作時 |
| 通知の送信ログ | 通知の種類・送信先ユーザーID・送信先チャンネルID・結果・エラー内容 | リマインド送信時 |
| 資材の記録 | 品目名・数量・増減した人のユーザーID | `/stock use` `/stock add` 等 |

### 2.2 サーバーに関する情報

| 情報 | 内容 |
|---|---|
| サーバーID・サーバー名・参加日時 | 本Botが招待された際に記録 |
| サーバー別設定 | 通知チャンネルID・ログチャンネルID・ロールID・サークル名・出欠絵文字などの設定値 |
| 班のマスタ | 各サークルが登録した班名・桁名 |
| 進捗管理の設定 | 連携先スプレッドシートID、Todoist プロジェクトとの紐付け |

### 2.3 認証情報

| 情報 | 取り扱い |
|---|---|
| Todoist API トークン | サーバー管理者が `/todoist-setup` のフォームから登録した場合のみ保存。**Fernet で暗号化して保存し、平文では保存しません**。復号鍵は運営者のサーバー上の環境変数にのみ保持します |
| メールアドレス | 外部データベースUI（Directus）を用いた閲覧環境を運営者が発行する場合に限り、招待先のメールアドレスを保存する枠（`guild_directus_access` テーブル）を持ちます。**現在、本Botのコマンドからこの情報が記録されることはありません** |

### 2.4 収集しない情報

本Botは次の情報を**収集しません**。

- **メッセージの本文**（`MESSAGE CONTENT` 特権インテントを要求しない設計です。
  本Botはスラッシュコマンド・リアクション・ボタン等の操作、およびサーバー参加イベントを契機に動作し、`on_message` ハンドラを持ちません）
- ダイレクトメッセージの内容
- 音声・ビデオ通話の内容
- メールアドレス（2.3 の例外を除く）、電話番号、住所、支払い情報
- Discord のパスワード等の認証情報
- 位置情報、端末情報、Cookie 等のトラッキング情報

## 3. 利用目的

収集した情報は次の目的にのみ利用します。

1. 日程調整・タスク管理・班/メンバー管理・桁巻き積層記録・機体進捗管理の各機能の提供
2. リマインドおよび通知の送信
3. 週次サマリー・出欠率・CSV 出力などの集計表示
4. 不具合の調査および本Botの改善
5. 不正利用・規約違反への対応

**運営者が導入サーバーのデータを、当該サーバーの運営支援以外の目的で
参照・利用することはありません。** 統計目的で他大学のデータを横断集計したり、
第三者へ提供したりすることもありません。

## 4. 保存場所

| 対象 | 保存場所 |
|---|---|
| 本Botのデータ全般 | 運営者が管理するサーバー（VPS）上の PostgreSQL データベース（`〈サーバー所在地〉`） |
| 実行ログ | 同サーバー上のログファイル。1ファイル 5MB・最大5世代でローテーションされ、古いものから自動的に破棄されます。ログにはユーザーIDやサーバーIDが含まれることがあります |
| Todoist のタスク | 導入サーバーが登録した Todoist アカウント内（Todoist 社のサーバー） |
| 進捗管理データ | 上記の PostgreSQL 内（Google スプレッドシートへの保存は廃止しました） |

## 5. 第三者への提供・外部送信

1. 運営者は、法令に基づく開示請求がある場合を除き、収集した情報を第三者へ提供しません
2. 本Botは機能の提供のため、次の外部サービスと通信します

| 送信先 | 送信する情報 | 条件 |
|---|---|---|
| Discord | コマンドへの応答・通知・DM | 常時 |
| Discord（OAuth2） | ログイン時の利用者識別（`identify` + `guilds` スコープ） | Web ダッシュボードにログインした場合のみ |
| Todoist | タスク名・期限・担当・ラベル等 | 導入サーバーが `/todoist-setup` を実行した場合のみ |

## 5.1 Web ダッシュボード

運営者は、Discord でログインして自分のサーバーのデータを表形式で
閲覧・編集できる Web ダッシュボードを提供する場合があります。

- ログインは Discord OAuth2（`identify` + `guilds` スコープ）のみを使い、
  メッセージや DM は取得しません
- セッションは署名付き Cookie に保存し、**アクセストークンは保存しません**
- 表示・編集できるのは、利用者が所属し、かつ本Botも参加している
  サーバーのデータに限られます
- 編集内容は監査ログ（`audit_log`）に記録されます
- 通信は HTTPS で保護されます

## 6. データの分離

導入サーバーのデータは、すべてのテーブルで `guild_id` により分離されています。
コマンドは実行元のサーバーにスコープされ、DM からの実行は拒否されます。
**ある大学のサークルのデータが、別の大学のサークルから参照されることはありません。**

## 7. 保存期間

1. **本Botをサーバーから退出（キック）させると、その30日後にデータは自動削除されます。**
   誤ってキックした場合や一時的に外した場合に備えた猶予期間です。
   猶予期間内に再度招待すれば、データはそのまま復活します
2. 保持日数はサーバーごとに変更できます（設定キー `DATA_RETENTION_DAYS`。
   `0` を指定すると退出した時点で削除対象になります）
3. 退出を待たずに削除したい場合は、サーバー管理者が `/data delete` を実行できます（次項）
4. 参加中のサーバーのデータは、削除の申告がない限り保存されます
5. 実行ログはローテーションにより古いものから自動的に破棄されます

## 8. 削除請求・開示請求

### 8.1 サーバー単位の削除（サーバー管理者が自分で実行できます）

**運営者への連絡は不要です。** サーバー管理者（「サーバー管理」権限、
または管理者ロール）が Discord 上で次を実行してください。

| コマンド | 内容 |
|---|---|
| `/data export` | 主要14テーブルを ZIP（CSV 群）で受け取る。削除前のバックアップに使えます |
| `/data delete` | 全データの削除を申告する。確認のためサーバー名の入力が必要です |
| `/data delete-cancel` | 削除が実行される前であれば取り消せます |

`/data delete` を実行すると、確認後に**最後のバックアップ ZIP がその場で渡され**、
次回の定期処理（毎日 04:00）で当該 `guild_id` に紐づく全レコード
（メンバー・出欠・タスク・積層記録・機体進捗・監査ログ・設定・
暗号化された Todoist トークンを含む）が削除されます。

サーバーから退出（キック）させた場合も、30日後に同じ処理で自動削除されます。

コマンドを実行できない事情がある場合に限り、`〈連絡先〉` へ
**サーバーID（`guild_id`）**（Discord の開発者モードを有効にし、サーバー名を
右クリック →「サーバーIDをコピー」で取得）と、請求者が当該サーバーの
管理権限を持つことの確認材料を添えてご連絡ください。

### 8.2 個人単位の削除・開示（利用者本人から）

自分に関する記録の削除または開示を希望する場合は、`〈連絡先〉` へ
**サーバーID（`guild_id`）とご自身の Discord ユーザーID** を添えてご連絡ください。

- 削除の対象: メンバー情報、出欠回答、自身が登録した積層記録、
  自身に紐づくタスクの担当者情報、監査ログ上の操作者ID
- 集計の整合性を保つため、**個人を識別できない形に置き換える方法**
  （ユーザーIDの削除・匿名化）で対応する場合があります
- サーバー管理者経由での請求も受け付けます

### 8.3 利用者自身で削除できるもの

次の情報は、請求を待たずに Discord 上から削除できます。

| コマンド | 削除される情報 |
|---|---|
| `/data delete` | このサーバーの全データ（管理者のみ。8.1 参照） |
| `/todoist-remove` | 当該サーバーの Todoist トークン（暗号文ごと削除） |
| `/task delete` | タスク |
| `/schedule delete` | 日程調整（無効化）。**出欠回答は残ります**（`/schedule restore` で戻せます） |
| `/layer keta-remove` | 桁名（無効化） |

無効化した日程調整の出欠回答を**完全に消す**には、`/data delete`（8.1）で
サーバー全体のデータを削除するか、8.2 の個人からの請求として運営者へご連絡ください。

データの持ち出しは `/data export`（管理者のみ）または Web ダッシュボードの
CSV 出力で行えます。書き出した CSV にサーバーIDや Todoist トークンは含まれません。

## 9. 安全管理措置

- Todoist API トークンは Fernet（AES-128-CBC + HMAC）で暗号化して保存し、
  復号鍵はデータベースとは別に運営者のサーバー上の環境変数のみに保持します
- すべてのデータアクセスは `guild_id` を必須引数とするリポジトリ層を経由します
- 本Botは特権インテントのうち `SERVER MEMBERS` のみを要求し、
  `MESSAGE CONTENT` を要求しません（メッセージ本文を取得できない状態で動作します）
- 招待時に要求する権限は最小限で、`Administrator` を要求しません

## 10. 未成年者の利用

本Botは学生団体での利用を想定しています。Discord の年齢要件を満たす利用者を
対象とし、それ未満の年齢の方の情報を意図的に収集することはありません。

## 11. 改定

本ポリシーは、機能追加や運用形態の変更に伴い改定されることがあります。
重要な変更を行う場合は、本Botの `#bot-log` チャンネルまたは `〈連絡先〉` を
通じて通知します。

## 12. 問い合わせ

本ポリシーに関する問い合わせ、削除請求・開示請求は `〈連絡先〉` までお願いします。
