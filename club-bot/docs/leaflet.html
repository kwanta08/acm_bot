HOW IT WORKS

入れるのは15分。VPS もトークンも要らない

招待URLを踏んで /setup を実行するだけ。サーバーの用意も設定ファイルの編集も、更新作業もありません。

鳥人間の言葉が、そのままコマンド

桁巻き・積層・主桁・機体。用語を汎用語へ言い換えません。新入生にも何のコマンドかが説明なしで伝わります。

サークルの形は、そのままでいい

班名・桁名・機体構成・チャンネルに初期値はありません。すべて Discord 上から、あなたのサークルが決めます。

メッセージの本文は読みません

MESSAGE CONTENT 特権インテントを要求しない設計。データもサーバー単位で完全に分かれています。

はじめかたは3ステップ

GET STARTED
1

招待する

招待URLを開いてサーバーを選ぶだけ。要求する権限は最小限で、Administrator は求めません。

2

/setup を実行

通知チャンネル・ロール・サークル名を選び、班名をカンマ区切りで入力。班とロールがまとめて作られます。

3

使い始める

/schedule create で最初の日程調整を。役割別の取扱説明書つきなので、引き継ぎも読むだけです。

安心して
使えます 本文を読まないメッセージ本文と DM を読む権限を持ちません サーバー単位で分離設定も通知も他サーバーから見えません トークンは渡さないTodoist の鍵は各サーバーで暗号化保存 やめるのも自由キックで停止し、30日後に自動削除

できること

毎日つかうものから、年に数回のものまで。すべて Discord のスラッシュコマンドで。

日程調整/schedule 全候補を1つの投票ボードに集約。締切で自動集計し、未回答者へ催促 DM。
タスク管理/task /today 期限つきタスクを班へ配って追いかける。正本は Todoist なので、いまの運用のまま Discord から。
桁巻き積層記録/layer 誰が・どの桁の・何層目を・何分。start → end の2コマンドで作業時間は自動計算。
機体進捗管理/progress 機体 → パーツ → 部品 のツリーを子から親へ再帰的に集計。積層記録と Todoist から反映。
重量管理/weight 目標重量と実測重量をツリーで積み上げ、超過の大きい順に表示。重量は成績に直結します。
大会からの逆算/milestone /countdown 大会日と節目から必要ペースを逆算。遅れがある週だけ月曜に通知します。
班・メンバー管理/team-* /member 班の作成とロール紐付け、班をまたいだ支援候補の検索、新入生オンボーディング。
資材の在庫/stock 消耗品の増減を記録し、発注閾値を割った朝だけ通知。「気づいたら無い」を防ぎます。
代替わり/season 卒業者の仕分け・班長フラグの一括リセット・年度スナップショット。記録は消しません。
持ち出しと削除/data 主要14テーブルを ZIP（CSV 群）で export。データは自分で削除できます（取り消し可）。
