- 版: 初版（公開時に発効）

## 1. 適用

本規約は、本Botの提供条件および本Botの利用に関する運営者と利用者の関係を定めるものです。
本Botをサーバーに招待した時点、または本Botのコマンドを実行した時点で、
本規約に同意したものとみなします。

## 2. 定義

| 用語 | 意味 |
|---|---|
| 運営者 | 本Botのインスタンスを運用する kwanta08 |
| 本Bot | 運営者が運用する Discord Bot 本体、およびそれに付随する機能 |
| 導入サーバー | 本Botを招待した Discord サーバー（ギルド） |
| サーバー管理者 | 導入サーバーで `サーバー管理` 権限、または本Botの管理者ロールを持つ利用者 |
| 利用者 | 導入サーバーに所属し、本Botの機能を利用する個人 |

## 3. 対象と目的

本Botは、**鳥人間サークル（人力飛行機・鳥人間コンテスト系の学生団体）の運営**を
支援する目的で提供されます。日程調整、タスク管理、班・メンバー管理、
桁巻き積層記録、機体進捗管理などの機能を提供します。

本Botは特定の団体の内部運営を対象としており、不特定多数への情報発信や
商用サービスの提供を目的とするものではありません。

## 4. 利用条件

1. 利用者は [Discord 利用規約](https://discord.com/terms) および
   [Discord コミュニティガイドライン](https://discord.com/guidelines) を遵守すること
2. 利用者は Discord が定める年齢要件を満たしていること
3. 導入サーバーへの本Botの招待は、当該サーバーの管理権限を持つ者が行うこと
4. サーバー管理者は、本Botが利用者の情報を記録することを所属メンバーへ周知し、
   [プライバシーポリシー](PRIVACY.md) を参照できる状態にすること

## 5. 提供形態と可用性

1. 本Botは**無償**で提供されます
2. 本Botは**ベストエフォート**での提供であり、稼働率・応答時間・データの保全について
   いかなる保証も行いません
3. 運営者は、保守・障害対応・仕様変更のため、事前の通知なく本Botの
   全部または一部を停止・変更することがあります
4. 本Botは開発途上であり、機能の追加・変更・廃止が行われることがあります

## 6. 禁止事項

利用者は、本Botの利用にあたり次の行為を行ってはなりません。

1. 法令または公序良俗に違反する行為
2. 運営者、他の導入サーバー、他の利用者に対する不利益・損害を与える行為
3. 本Botに対する過度な負荷を意図的に発生させる行為、および自動化された大量リクエスト
4. 本Botの脆弱性を悪用して、権限のないデータへアクセスまたはアクセスを試みる行為
5. 本Botのアカウント・トークン・認証情報を不正に取得または利用する行為
6. 他人になりすまして本Botを操作する行為
7. その他、運営者が不適切と合理的に判断する行為

## 7. 利用者が入力する情報

1. 利用者およびサーバー管理者は、本Botへ入力する情報について、
   自らその内容に責任を負うものとします
2. 本Botのメモ欄・タスク名・説明欄などの自由記述欄に、
   **機微な個人情報（健康状態、信条、経済状況等）を入力しないでください**
3. Todoist 連携を利用する場合、サーバー管理者は自身の責任において
   API トークンを登録するものとします。トークンは暗号化して保存されますが、
   連携先サービスの利用条件はそれぞれのサービス提供者との間で適用されます
4. Web ダッシュボードからエクスポートした CSV の取り扱い（保存先・共有範囲）は、
   ダウンロードした利用者の責任とします

## 8. データの取り扱い

本Botが記録する情報の種類、保存場所、保存期間、削除請求の方法は
[プライバシーポリシー](PRIVACY.md) に定めます。

導入サーバーのデータは `guild_id` 単位で分離され、他の導入サーバーから
参照できない設計としています。

## 9. サービスの終了とデータの削除

1. 運営者は、本Botの提供を終了する場合、可能な限り事前に導入サーバーへ通知します
2. 提供終了時、運営者は保有するデータを削除します
3. **本Botをサーバーから退出（キック）させると、その30日後にデータは自動的に
   削除されます。** 誤操作に備えた猶予期間であり、その間に再招待すれば
   データはそのまま復活します。保持日数はサーバーごとに変更できます
4. 退出を待たずに削除する場合、サーバー管理者は `/data delete` を実行できます。
   削除前のバックアップは `/data export` で取得してください
5. 詳細は [プライバシーポリシー](PRIVACY.md) の「保存期間」「削除請求」を参照してください

## 10. 第三者サービス

本Botは次の外部サービスと通信します。各サービスの利用条件・プライバシーポリシーは
それぞれの提供者が定めるものが適用されます。

| サービス | 用途 | 利用条件 |
|---|---|---|
| Discord | 本Botの動作基盤 | 常時 |
| Todoist | タスク連携 | 導入サーバーが `/todoist-setup` を実行した場合のみ |

## 11. 免責

1. 運営者は、本Botの利用または利用不能によって生じた損害について、
   運営者の故意または重過失による場合を除き、責任を負いません
2. データの消失・破損、通知の未達・遅延、第三者サービスの障害に起因する
   不具合について、運営者は責任を負いません
3. 導入サーバー内での本Botの運用（誰にどの権限を与えるか、どの情報を
   入力するか）については、当該サーバーの管理者が責任を負うものとします
4. 本Botはサークル運営の補助ツールであり、**機体の安全性・製作品質・
   作業の適法性を保証するものではありません**。設計・製作・試験に関する
   判断は各サークルの責任において行ってください

## 12. 規約の変更

運営者は本規約を変更することがあります。重要な変更を行う場合は、
本Botの `#bot-log` チャンネル、または GitHub リポジトリ上で通知します。
変更後も本Botの利用を継続した場合、変更後の規約に同意したものとみなします。

## 13. 準拠法・管轄

本規約は日本法に準拠します。本Botに関して紛争が生じた場合、
運営者の所在地を管轄する日本の裁判所を第一審の専属的合意管轄裁判所とします。
