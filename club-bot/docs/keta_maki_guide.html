桁巻きガイド

一般班員向け　/layer コマンドの使い方 — 作業を記録して、機体進捗に自動反映

このガイドについて

桁巻き（積層）の作業をするとき、サークルの Discord bot に 「いつ・誰が・どの桁の・何層目を」 作業したかを記録します。記録は自動で集計され、機体全体の進捗にも自動で反映されます。 使うコマンドは基本 2つだけです。始めるときに /layer start、終わったら /layer end。

1. 基本の流れ（まずはこれだけ）

図1　桁巻き記録の基本フロー：start して巻いて end するだけ
ポイント
コマンドはすべてサークルの Discord サーバー内で実行します（DMでは使えません）。 実行結果は自分にだけ表示されるので、チャンネルを汚す心配はありません。

記録した内容は自分の作業時間の集計に使われるほか、桁ごとの完了層数として集計され、 機体全体の進捗表示（/progress view）にも自動で反映されます（くわしくは 5章）。

2. コマンド一覧

コマンドなにをする？使える人
/layer start積層の開始を記録する（桁名・層番号を指定）全員
/layer end進行中の積層を終了し、作業時間を自動計算して保存全員
/layer status今、誰がどの桁の何層目を巻いているかの一覧全員
/layer keta-list登録されている桁名の一覧を表示全員
/progress view機体製作の進捗をドリルダウン表示（桁巻きの反映先）全員
/layer keta-add / keta-remove桁名の登録・無効化（新しい桁を巻き始めるときに班長へ依頼）班長以上
/progress spar-link桁と進捗ノードの紐付け・目標層数の設定班長以上

3. 各コマンドの使い方

3.1　/layer start — 積層を始めるとき

/layer start keta:主桁1 layer_num:5
  • keta（桁名）：入力欄をタップすると登録済みの桁名が候補に出るので、選ぶだけでOK。
  • layer_num（層番号）：数字（例 5）のほか、「シュリンク」などのテキストでもOK。
  • 候補に目当ての桁名が出ないときは未登録です。班長に /layer keta-add での登録を頼みましょう。

3.2　/layer end — 作業が終わったら

/layer end
  • 入力項目はありません。実行すると開始から終了までの作業時間（分）が自動計算されて保存されます。
  • 終了できるのは自分が start したセッションだけ。他の人の記録を代わりに終わらせることはできません。

3.3　/layer status — 今の状況を見る

/layer status → 例）山田: 桁 主桁1 / 5 / 経過 42 分
  • 進行中の全員分の「誰が・どの桁・何層目・経過何分」が一覧で見られます。
  • 作業の交代前や、end を忘れていないかの確認に便利です。

3.4　/layer keta-list — 桁名の一覧

/layer keta-list → ✅ 主桁1　✅ 主桁2　⛔ 旧桁（無効化済み）

セッションのルール：同時に持てるのは1つだけ

図2　セッションの状態遷移：start 中にもう一度 start はできない
注意
  • 桁名や層番号を間違えて start してしまったら、いったん /layer end で終了してから、正しい内容で /layer start し直してください。
  • end を忘れると経過時間が伸び続けます。作業を終えたら（休憩・帰宅の前に）必ず end しましょう。

4. ルールと注意点まとめ

ルール説明
サーバー内で実行するDMではコマンドを使えません。サークルのDiscordサーバー内のチャンネルで実行します。
結果は自分にだけ見えるコマンドの応答は本人にのみ表示されます。気軽に実行してOK。
セッションは1人1つまで進行中のまま別の桁を start することはできません。先に end してから。
自分の記録は自分で操作他の人のセッションを代わりに終了することはできません。
桁名は登録制start で選べるのは登録済みの桁名だけ。新しい桁は班長に登録を依頼。
層番号は柔軟に入力可数字のほか「シュリンク」などの工程名テキストも記録できます。

5. 進捗への自動反映のしくみ

/layer end で保存された記録は、それだけで終わりません。 班長が桁と機体進捗のノードを紐付けておくと（/progress spar-link）、 完了した層数から進捗率が自動計算され、機体全体の進捗ツリーに反映されます。 一般班員は特に操作不要— 普段どおり start / end していれば進捗が育ちます。

図3　記録から機体進捗への自動反映の流れ
つまり…
あなたの1回1回の /layer start → /layer end が、そのまま機体全体の進捗表示になります。 記録漏れがあると進捗も実際より低く表示されるので、忘れず記録しましょう。

進捗を見てみよう — /progress view

/progress view → 機体 → 主翼 → 主桁 …とボタンでたどると、各部位の進捗率・状態・担当が見られます

自分の巻いた桁がどのくらい進んだか、いつでも確認できます。進捗率のほかに 「状態」も自動で切り替わります：0% = 未着手／途中 = 製作中／100% = 完了。

6. 困ったときは（Q&A）

症状対処
/layer start で「桁名『◯◯』は登録されていません」と出る その桁名は未登録です。候補に出る登録済みの桁名から選ぶか、班長に /layer keta-add での登録を依頼してください。
「既に進行中のセッションがあります」と出る 前の作業が end されていません。/layer end で終了してから、あらためて start してください。
/layer end で「進行中のセッションがありません」と出る start を実行していない状態です。先に /layer start を実行してください。（他人の記録を代わりに終わらせることはできません）
桁名や層番号を間違えて start してしまった いったん /layer end で終了し、正しい内容で /layer start をやり直してください。
end し忘れて帰ってしまった 気づいた時点で /layer end を実行してください。作業時間が実際より長く記録されるので、班長に一言伝えておくと安心です。
自分の記録が進捗に反映されていない気がする 反映は約20分ごとの自動同期です。少し待ってから /progress view を確認してください。それでも反映されない場合は、桁の紐付け（spar-link）がまだかもしれないので班長へ。
